# Foundations

All values live in `design/tokens.css` as CSS custom properties. The library imports that file and refers to tokens only through `var(--…)`.

## Type

Inter stands in for the licensed GT Walsheim Pro and GT America. Use tabular figures (`font-variant-numeric: tabular-nums`) for every number in a table, KPI or axis.

| Role | Token | Size / weight |
| --- | --- | --- |
| Poster headline | `--text-display`, `--text-heading-lg` | 64–100px / 700, tight negative tracking |
| Card title | `--text-subheading` | 24px / 600 |
| KPI number | `--text-heading-sm` | 32px / 600, tabular |
| Body | `--text-body`, `--text-body-sm` | 18 / 16px / 400 |
| Tag and label | `--text-tag` | 10px / 600, uppercase, +0.4px |

## Shape, space, elevation

| Token | Value | Use |
| --- | --- | --- |
| `--radius-cards` | 12px | Every card |
| `--radius-full` | 9999px | Everything you press: buttons, tags, toggles, slider thumbs |
| `--radius-nav` | 24px | The nav pill |
| `--card-padding` | 24px | Card padding |
| `--section-gap` | 48px | Space between sections |
| `--page-max-width` | 1200px | Content width |
| `--shadow-xl` | navy-tinted 9/25 | Cards on fog |
| `--shadow-md` | navy-tinted 6/16 | Nav pill, tooltips |
| `--shadow-sm` | navy-tinted 1/4 | Filled buttons, active tab |
